JOHN PAUL TECH WEBSITE

Files:
- index.html        Main/Home page
- contact.html      Contact + Customer Service page
- style.css         All styling, responsive layout, animations and dark/light mode
- script.js         Navigation, theme switcher, gallery lightbox, back-to-top and WhatsApp form

HOW TO OPEN:
1. Put all four files in the same folder.
2. Open index.html with Chrome, Edge, Firefox or another modern browser.
3. Internet is needed for the gallery images from Unsplash and for WhatsApp links.

IMPORTANT:
- The contact form sends the enquiry to WhatsApp; it does not require a paid server.
- To use your domain www.johnpaultech.ong, you must register the domain and connect it to web hosting. The code itself does not publish a website to the internet.
- Replace the sample gallery images with your own work when ready.
